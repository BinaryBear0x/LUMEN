# LUMEN kategori görselleri

Bu dokuz PNG, LUMEN için imagegen ile üretildi. Görseller gerçek alfa kanallı şeffaf arka plan taşır ve `PageMotif` tarafından gösterilir. Ortak istem: Warhammer 40,000 karakter tasarımına bağlı, erkek ya da cinsiyetsiz mekanik karakter; şeffaf zeminde kompakt hibrit pixel art, kemik/gunmetal/pirinç ve sınırlı yeşil ışık; yazı, çerçeve ve sahne arka planı yok.

| Dosya | Karakter ve sayfa ilişkisi |
| --- | --- |
| `control.png` | Adeptus Mechanicus Tech-Priest, ışık küresiyle kontrol |
| `devices.png` | Adeptus Mechanicus servitor, ampulleri inceleme |
| `schedules.png` | Maskeli Tech-Priest, gotik kronometre |
| `effects.png` | Space Marine Librarian, ışık etrafında psişik efekt |
| `profiles.png` | Mechanicus Magos, renkli veri tüpleri |
| `music.png` | Chaos Noise Marine, sonik blaster |
| `notifications.png` | Haberci servo skull, yeşil ikaz lambası |
| `environment.png` | Cadian keşif askeri, auspex ile çevre taraması |
| `focus.png` | Dark Angels Space Marine, dua ve kum saati |

Kaynak görsellerin yerini alan bu dosyalar yalnızca dekoratif UI varlıklarıdır; uygulama davranışını değiştirmez.
